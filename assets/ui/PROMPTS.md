# Cinderwake interface assets

Generated with the built-in ImageGen tool. Original alpha PNGs are embedded by src/ui_skin.rs; all labels, values, cooldowns and meter fills remain live engine UI. The panel uses nine-slice scaling, and icons preserve aspect ratio.

## frames-v1.png

Use case: stylized-concept.
Asset type: a production game UI frame atlas on genuine transparent background for Cinderwake, a copper-and-glass clockwork fantasy action platformer.
1536 x 1024 image, exactly 2 columns and 2 rows of isolated elements, each cell 768 x 512. At least 36 px transparent gutter. Four completely separate UI parts:
Top left: broad rectangular menu/dialog frame, 680 x 414, centered in cell. Deep near-black navy inset center, subtle hammered obsidian texture, aged brass double rim, thin oxidized teal accents. Compact elegant gothic scrollwork at CORNERS ONLY. Keep the vast center empty and dark for readable dynamic text.
Top right: a horizontal vitality/boss-meter housing, 680 x 112, centered in cell. Very long empty dark navy rectangular channel, fine brass edges, small angular ornate end caps, no filled meter, no writing. Rim thin relative to channel.
Bottom left: square equipment-slot frame, 330 x 330, centered in cell. Recessed navy center, beveled antique brass rim, restrained little teal jewel rivets in four corners. Center is EMPTY for an icon.
Bottom right: horizontal button/plaque, 680 x 142, centered in cell. Empty dark inset for text, aged brass end caps and border, tiny copper scroll details confined to ends.
Style: exceptionally crisp detailed pixel art with small deliberate pixel clusters and cel shaded 3-tone metal facets. Match richly drawn indigo/copper ruined-gothic-game sprites. Fine designed pixels, no giant chunky blocks, no blurry photo textures. Warm ivory specular highlights, patina teal, dark midnight blue. Strong contrast and tactile beveled metal. Orthographic flat UI, not perspective.
Constraints: no letters, numbers, symbols resembling text, watermarks, characters, scenery, arrows, full screen mockup or labels. No central ornaments on frame borders; borders must stretch as nine-slice UI, corner details stay local. Opaque dark interiors, transparent exterior. All four elements entirely contained in their cells, no shadows outside silhouette.
